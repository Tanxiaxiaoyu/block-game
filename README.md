# 别踩白块游戏 🎵

一个经典的别踩白块小游戏，使用纯HTML、CSS和JavaScript实现。

## 🎮 游戏特性

- 🎯 四列轨道经典玩法
- ⚡ 速度递增挑战
- 🏆 最高分记录
- 📱 响应式设计，支持移动端
- 🚀 流畅60fps动画

## 🕹️ 如何游玩

1. 打开游戏页面
2. 点击"开始游戏"按钮
3. 点击黑色方块消除它们并得分
4. 避免点击白色方块！
5. 看看你能得多少分？

## 🛠️ 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)

## 📦 部署

游戏已配置GitHub Pages部署，可直接访问线上版本。

## 🎨 游戏规则

- 点击黑色方块：将方块消除并获得1分
- 点击白色方块：游戏结束
- 每得10分，速度增加10%
- 最高速度为基础速度的3倍

## 📝 开发

如需本地运行，只需在浏览器中打开 `index.html` 文件即可。
